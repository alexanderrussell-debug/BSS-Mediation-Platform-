UMS - release history
=====================

5.3.0 (unreleased) - Java 21 migration

    job stays non-concurrent), Log4j 1.2.17 -> reload4j 1.2.26 (+ slf4j-reload4j for Quartz/Spring logs),
    Commons Net 2.2 -> 3.11.1, JUnit 4.10 -> 4.13.2 (SEC-2024-022)
  - bin/ums.sh: JAVA_HOME default JDK 21, -XX:MaxPermSize / CMS removed, G1 explicit; heap,
    -Dfile.encoding=ISO-8859-1, PID file and start/stop/status unchanged
  - Dockerfile on Temurin 21 images
